# React — доска как SPA

Портал: http://localhost:4321/tracks/web/react

Папка должна быть почти пустой перед `npm create vite@latest . -- --template react` (шаблон **react**, не react-ts). Затем `npm install` и `npm run dev`.

Пакеты ставятся в локальный `node_modules`, не глобально. Create React App не используем.
