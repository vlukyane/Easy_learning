# Learning

Портал курсов: разделы **AI** и **Web**. Прогресс глав и чеклистов — в `localStorage` этого браузера.

## Запуск

Node 22 (`.nvmrc`):

```bash
nvm use
npm install
npm run dev
```

Открой http://localhost:4321 — каталог разделов.

- AI: `/tracks/ai` (шесть проектов из [LEARNING_PLAN.md](LEARNING_PLAN.md))
- Web: `/tracks/web` (HTML → CSS → JS → React → Vite → Zustand)

Старые ссылки `/courses/fieldnote` редиректятся на `/tracks/ai/fieldnote`.

Клавиши в плеере: `←` / `→`.
