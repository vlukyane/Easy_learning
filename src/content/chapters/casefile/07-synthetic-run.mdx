Синтетика здесь лучше реальных претензий: у тебя есть ground truth маршрута.

<Scaffold path="projects/casefile/data/claims.jsonl.example">
Шаблон строк. Скопируй схему в `data/claims.jsonl` (уже без `.example`) и набери 50–100 заявок. Батч — `run_batch` в `src/orchestrator.py`: печать сводки и запись `logs/batch-summary.json`.

**Поля строки:** `claim_id`, `narrative`, `claimed_amount`, `incident_date`, `expected_route` (список состояний), `is_fraud`, `notes`.

**Классы (минимум по несколько штук):**
- чистые простые (как CLM-001 → до `payout_gate`);
- high-fraud (как CLM-002 → `human_review`, без assess);
- большая сумма (HITL);
- тяжёлые по токенам (потолок, `stopped_cost_ceiling`);
- мусорный нарратив (ошибка intake).

**Чего не делать:** не клонируй 50 одинаковых «rear bumper». Без известного `expected_route` батч не измерить. Не подгоняй маршруты после просмотра ошибок модели — чини агентов или честно считай mismatch.
</Scaffold>

Собери 50–100 строк. Минимум классов:

- чистые простые
- high-fraud
- большая сумма (HITL)
- тяжёлые по токенам (потолок)
- мусорный нарратив (ошибка intake)

`expected_route` — список состояний, например `intake,classify,fraud,human`.

<Command cwd="projects/casefile" title="Батч" code={`python -c "from src.orchestrator import run_batch; run_batch('data/claims.jsonl', limit_usd=0.15)"`} />

Сводка, которую обязан напечатать батч:

- число заявок
- доля точных попаданий в `expected_route`
- 0 payouts without approval (инвариант)
- доля `stopped_cost_ceiling`
- средние центы на заявку
- 0 `ValidationError` на хендоффах

Ожидаемая форма `logs/batch-summary.json`:

```json
{"n_claims": 60, "route_match": 0.92, "payouts_without_approval": 0,
 "stopped_cost_ceiling": 0.12, "cents_per_claim": 0.31, "validation_errors": 0}
```

<Metric>
Инварианты: 0 выплат без approval, 0 необработанных превышений ceiling (либо stop, либо ты поднял лимит осознанно), 0 ошибок парсинга. Плюс одно число: ¢/claim.
</Metric>

<Checkpoint>
**Готово, когда:** сводка батча существует и инварианты посчитаны числами, а не «вроде не падало».

**Как проверить:** открой `logs/batch-summary.json`: n ≥ 50, route-match, три нуля, центы на заявку. Сверь пару трасс с `expected_route` глазами.

**Ещё рано, если:** меньше 50 строк; нет `expected_route`; сводка только в терминале; инварианты «на глаз».
