## Что это

В Vite **вход — HTML**, не спрятанный «виртуальный бандл без файла». Браузер всегда начинает с документа. `<script type="module" src="/src/main.jsx">` — корень **модульного графа**: из `main.jsx` тянутся `App`, стор, CSS… Vite строит дерево зависимостей от этих import.

- **`src/`** — код, который **обрабатывают**: JSX, импорты, картинки как модули (получат хеш в имени при сборке).
- **`public/`** — файлы **копируются как есть**. URL `/favicon.svg` = файл `public/favicon.svg`. Не импортируй их из JS как модули.

## Зачем

Положил фото в `public`, а импортируешь как из `src` — путь не тот. Положил JSON в `src` и ждёшь `/cards.json` — его нет в корне сайта, пока не импортируешь. Путаница «картинка 404» почти всегда про эту границу.

Удалил `index.html` — Vite не знает, что отдавать: входа нет.

## Как работает

Картинка из `src/assets` — `import url from './assets/x.png'`. Картинка, которая должна быть `https://site/photo.jpg` без хеша — в `public/`.

Новой установки нет: Node уже есть.
