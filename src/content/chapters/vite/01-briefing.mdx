## Что это

**Vite** — **dev-сервер** и **сборщик**. Браузер не умеет удобно `import` сотни файлов с **JSX** прямо с диска: JSX — не стандартный JS, путей много, `node_modules` огромный.

- **Dev:** нативные **ESM** (браузер сам грузит модули по URL) + быстрое преобразование JSX/TS на лету. Зависимости из npm предсобираются отдельно.
- **Prod (`build`):** склейка в бандл, минификация, хеши в именах файлов. Другой конвейер (Rollup). Поэтому баг «только в проде» возможен: путь, который прощал dev, падает в сборке.
- **HMR** — горячая подмена модуля: сохранил компонент — обновился кусок, часто без полного F5.

Аналогия: в dev повар отдаёт ингредиенты по одному (модули). В prod — уже готовый контейнер еды (`dist`).

## Зачем

`open index.html` хватило визитке. React-граф с JSX без инструмента — ошибки MIME, CORS на `file://`, ручной Babel. Без понимания dev≠prod новичок чинит HMR, а сломался бандл.

Create React App прятал webpack. Здесь конфиг короткий и твой.

## Как работает

`npm run dev` поднимает HTTP. Браузер просит `/src/main.jsx` — Vite компилирует и отдаёт. Сохранение файла — HMR-сообщение клиенту. `npm run build` обходит граф импортов, пишет статику в `dist`.
