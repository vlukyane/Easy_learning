## Что это

**Конфиг** — файл с настройками инструмента: порт dev-сервера, плагины, короткие имена путей. Без него Vite работает «из коробки»; ты пишешь конфиг, когда стандарт неудобен.

**Плагин** — расширение конвейера. **Плагин React** (`@vitejs/plugin-react`): JSX → обычный JS, **Fast Refresh** (HMR для компонентов). Без него `.jsx` — просто ошибка.

**Alias** — короткое имя пути (`@` → папка `src`), не новая библиотека и не npm-пакет. `import x from "@/components/Board.jsx"` = тот же файл, что длинный относительный `../../../`.

## Зачем

Боль: `import` из `../../../../store` ломается при переносе файла. Alias стабилен. Порт 5173 занят другим Vite — без `server.port` или флага сидишь и думаешь, что «не запускается».

## Как работает

Файл в корне React-приложения (часто `vite.config.js`):

```js
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import path from "node:path";
import { fileURLToPath } from "node:url";

const root = path.dirname(fileURLToPath(import.meta.url));

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: { "@": path.resolve(root, "src") },
  },
  server: { port: 5173 },
});
```

После alias: `import { Board } from "@/components/Board.jsx"`.

Перезапусти `npm run dev` после смены конфига.
