Vite — ответ на «браузер не ест сырой JSX-граф». Dev — модули и скорость. Prod — папка `dist`. Alias — короткий путь. `VITE_` — сознательно публичные значения.

Своими словами повтори: вход HTML, `src` vs `public`, preview не dev, HMR не вечен.

<DoD>
- `npm run build` без ошибок.
- `preview` открывает доску.
- Alias `@` указывает на `src`.
</DoD>
