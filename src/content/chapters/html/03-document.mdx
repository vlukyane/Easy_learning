## Что это

**Документ HTML** — не «текст в файле», а договорённый каркас: браузер должен понять, *как* разбирать файл и *где* служебное, а где видимое.

- **`<!DOCTYPE html>`** — первая строка. Это не тег. Он говорит: разбирай по правилам HTML5, не как старый Internet Explorer («quirks mode»). Без него отступы и размеры коробок ведут себя странно — ты будешь винить CSS.
- **`<html>`** — корень дерева. Атрибут `lang="ru"` — язык страницы: скринридер выбирает голос, браузер — переносы слов.
- **`<head>`** — для машины: кодировка, заголовок вкладки, как масштабировать на телефоне. Человек `head` почти не видит.
- **`<body>`** — для человека: всё, что на экране.

**Заголовки `h1`–`h6`** — иерархия смысла («глава / раздел / подраздел»), не размер шрифта. Размер потом задаст CSS. На странице один главный `h1`. После него `h2`, не прыжок на `h4` «потому что мельче».

## Зачем

Пустой файл «Привет» браузер покажет. Но без `charset` кириллица станет кракозябрами. Без `viewport` телефон сделает вид, что страница шириной как монитор, и уменьшит её — пальцем не попасть. Без `title` вкладка называется «index.html». Без одного `h1` и скринридер, и поисковик не знают тему страницы.

## Как работает

Браузер читает файл сверху вниз. Сначала DOCTYPE — режим. Потом строит дерево: `html` → `head` + `body`. Мета `charset` должна быть **в начале `head`**, до любого текста: иначе первые байты уже «угадали» кодировку неправильно.

`viewport` с `width=device-width` говорит: ширина раскладки = ширина экрана устройства, масштаб 1. Это ещё не адаптивный дизайн — это чтобы CSS в следующей теме мог работать с реальной шириной, а не с выдуманными 980px.

Минимум документа:

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>Визитка</title>
  </head>
  <body>
    <h1>Имя</h1>
  </body>
</html>
```
