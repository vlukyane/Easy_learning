## Что это

Текст на странице — не «просто буквы». Браузер решает, где блок, где кусок строки, где список, где ссылка.

- **`<p>`** — абзац: отдельный **блок**. Между соседними абзацами браузер рисует вертикальный зазор. Не склеивай мысли через `<br><br>` — это перенос строки, не абзац.
- **`<span>`** — кусок **внутри** строки, без своего абзаца. Нужен, когда часть предложения надо пометить (класс, язык), но не начинать новый блок.
- **`<strong>` / `<em>`** — смысл: важное / акцент. Браузер часто делает жирным/курсивом, но это побочный эффект. Для «просто жирного» без смысла позже будет CSS `font-weight`.
- **Список:** `<ul>` — маркированный (порядок не важен), `<ol>` — нумерованный (шаги, рейтинг). Пункт всегда `<li>`. Списки можно вкладывать: `ul` внутри `li`.
- **Ссылка `<a>`:** атрибут `href` — URL. Абсолютный (`https://…`) ведёт в интернет. Относительный (`board.html`) — соседний файл. `#contacts` — якорь на этой же странице.
- **Картинка `<img>`:** растр (jpg/png/webp) — сетка пикселей в файле. `src` — откуда взять. `alt` — текст, если картинки нет или человек не видит экран.

Рядом по смыслу, на одно предложение: **`<blockquote>`** — чужая цитата; **`<code>`** — короткое имя в строке; **`<pre>`** — блок, где пробелы и переносы как в файле (часто вокруг `code`).

## Зачем

Если всё запихнуть в один `<div>`, скринридер прочитает простыню, поиск не найдёт списка навыков, картинка без `alt` для незрячего — дыра. Ссылка «клик сюда» не говорит, куда попадёшь, когда читаешь список ссылок.

## Как работает

`<p>Раз.</p><p>Два.</p>` — два блока друг под другом. `<span>Раз</span><span>Два</span>` — в одной строке, без зазора абзаца.

`href="photo.jpg"` ищет файл **относительно папки HTML**, не относительно домашней папки и не «где файл лежал, когда копировал». URL с пробелом (`My Photo.jpg`) ломается: пробел в адресе надо кодировать, проще переименовать в `photo.jpg`.

`alt` не «SEO-магия». Это замена картинки: сломался путь — видишь текст; VoiceOver — слышишь описание. Пустой `alt=""` значит «декор, пропусти». У портрета alt обязателен.
