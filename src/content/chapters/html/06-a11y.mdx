## Что это

**Семантика** — правильное имя роли куска страницы для браузера и скринридера, не «красивое имя класса». `<header>` значит «шапка», даже если CSS сделает её зелёной. `<div class="header">` для машины — просто коробка.

**Landmarks** (ориентиры): `header`, `nav`, `main`, `footer` — точки, к которым можно перескочить голосом или списком регионов, не читая всё подряд. На странице обычно **один** `main`.

**Фокус** — «сейчас активен этот контрол». Клавиша **Tab** ходит по ссылкам, кнопкам, полям. Браузер рисует обводку (`outline`). Убрать её без замены = ловушка для клавиатуры.

Почему `div` + класс не заменяет:

- **`button`** — Enter/Пробел, роль «кнопка», фокус из коробки.
- **`a href`** — переход, среднее колёсико, «открыть в новой вкладке».
- Див с `onclick` — ни клавиатуры, ни роли, пока не навесишь кучу атрибутов вручную. Не надо.

## Зачем

Доступность — не «потом для слабовидящих». Ты сам Tab-ом проверяешь формы. Поисковик и расширения читают те же ориентиры. Семантика дешевле, чем чинить «див-суп» в React.

## Как работает

Замени обёртки:

- шапка сайта → `<header>`
- меню ссылок → `<nav>`
- основной смысл страницы → один `<main>`
- низ → `<footer>`

Не клади `main` внутрь `header`. Не делай пять `h1`. После `h1` идёт `h2`, не `h4` «потому что меньше».

Фокус: ссылки и поля должны иметь видимое состояние `:focus` — пока браузерное по умолчанию достаточно; в CSS не делай `outline: none` без замены.

Класс можно добавить на `header` (`<header class="site-header">`) — тег всё равно несёт роль.
