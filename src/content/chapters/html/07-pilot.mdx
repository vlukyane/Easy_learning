## Что это

**Пилот** — собрать страницу из уже известных кирпичей: каркас, текст, списки, ссылки, форма, ориентиры. Нового языка нет. Есть **композиция**: визитка про тебя и черновик Доски учёбы (три колонки «сделать / в работе / готово»).

**Две страницы со ссылками** — многостраничность без роутера. Браузер просто открывает другой файл. React Router появится сильно позже и не отменяет эту модель: у сайта по-прежнему есть адреса и документы.

## Зачем

Одна простыня «всё в index» плохо масштабируется: визитка и доска — разные задачи. Ссылки туда-сюда проверяют, что ты понимаешь относительный `href`, а не только «файл открылся из Finder».

## Как работает

Собери две зоны в одном `index.html` **или** два файла: `index.html` (визитка) и `board.html` (доска) со ссылками друг на друга (`<a href="board.html">`).

Доска:

- `<h1>Доска учёбы</h1>`
- три колонки: Сделать / В работе / Готово — пока три `<section>` или три `div` с `h2` и списками;
- в каждой — `<ul>` с 2–3 карточками-заголовками глав (например «HTML: стенд», «CSS: flex»).

Пока колонки могут идти друг под другом. Это нормально: HTML описывает порядок в документе. Ряд из трёх колонок — задача CSS (flex/grid), не таблица «для вида».

Второй документ пилота (можно всё держать в одном `index.html`, но две страницы лучше проверяют ссылки).

В `index.html` добавь `<a href="board.html">Доска учёбы</a>`. В `board.html` — `<a href="index.html">Визитка</a>`. Файлы лежат в одной папке, иначе относительный href сломается.

**Готово, когда:** `open index.html` и `open board.html` (или якоря) работают без сервера, без CSS-«красоты», визитка и доска связаны ссылками.

**Ещё рано, если:** колонки «понарошку» одним абзацем; нет обратной ссылки; файлы открываются только из VS Code Live Preview и ты не проверил `open`.
