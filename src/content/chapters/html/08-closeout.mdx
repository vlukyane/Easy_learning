HTML описывает **структуру и смысл**. Страница уже «существует», даже если серая и в столбик: браузер построил дерево, ссылки кликаются, форма собирает поля. **CSS** ещё не нужен, чтобы документ был документом. **JS** ещё не нужен, чтобы текст и картинка были на экране.

Своими словами, без подглядывания в конспект:

- тег, элемент, атрибут — три разных слоя;
- `head` для машины, `body` для человека;
- `p` — абзац, не `div` и не пачка `br`;
- форма живёт `name` + `label` + настоящая кнопка;
- `file://` открывает файл с диска, это ещё не сайт на сервере.

<DoD>
- `open index.html` показывает визитку.
- Структура читается без стилей.
- Форма с настоящими `label`.
</DoD>

<Checkpoint>
**Готово, когда:** HTML-пилот открывается как файл с диска, смысл страницы читается без стилей, Node не установлен «для HTML».

**Как проверить:** новый терминал → cd в html → pwd → ls → open. Исходник страницы — твой.

**Ещё рано, если:** страница серая и пустая без h1; форма из div; открывается не та папка; ты уже переписал всё на React.
