## Что это

**Таблица** — сетка **данных**: строки и ячейки. Строка — `<tr>`. Ячейка данных — `<td>`. Ячейка-заголовок колонки или строки — `<th>`. Шапка таблицы живёт в `<thead>`, тело — в `<tbody>`. Это не способ «нарисовать три колонки сайта»: для раскладки страницы позже будут flex и grid.

**Форма** — набор полей, который браузер умеет **собрать в запрос**. Ты подписываешь каждое поле атрибутом `name` — это ключ в посылке (`email=you@mail`). Без `name` поле на экране есть, в запрос не попадёт.

Типы `input` (не все, а нужные пилоту):

- `text` — обычная строка;
- `email` — почта, браузер может проверить вид адреса;
- `password` — символы скрыты, это не шифрование;
- `checkbox` — да/нет.

**`<label>`** связан с контролом: `for` у подписи = `id` у поля. Клик по тексту «Почта» ставит курсор в поле.

**Кнопка:** `<button type="submit">` отправляет форму. `<input type="submit">` — старый вариант той же идеи. `<div>` с надписью «Отправить» кнопкой не является: нет клавиатуры, нет Enter.

## Зачем

Таблица без `th` — решётка линий, скринридер не знает, что столбец называется «статус». Форма без `label` — только «поле», пока не догадаешься по placeholder (а placeholder исчезает, когда печатаешь). Без понимания GET/POST ты потом удивишься, что пароль торчит в адресной строке.

## Как работает

На **submit** браузер берёт `action` (куда) и `method` (как).

- **GET** — данные дописываются в URL (`?email=…`). Можно сохранить ссылку, видно в истории. Не для паролей и длинных текстов.
- **POST** — данные в теле запроса, URL чистый. Для отправки «по-настоящему» нужен сервер. У нас сервера нет: `action="#"` или пустой action просто **перезагрузит** страницу. Это нормально. В JS повесишь `preventDefault` и сохранишь карточку в массив.

Связка label:

```html
<form action="#" method="get">
  <label for="email">Почта</label>
  <input id="email" name="email" type="email" required />
  <button type="submit">Отправить</button>
</form>
```

Таблица — для табличных данных (расписание, сравнение), не для сетки страницы.

Placeholder не заменяет label.
