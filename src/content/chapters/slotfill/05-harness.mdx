Гоняет A и B по test. Считает field-level accuracy (микро по полям и макро по документам / exact-match документа).
</Scaffold>

Правила честности:

- Один `test` список id.
- Один парсер JSON → схема.
- Пустое поле = ошибка, не «пропуск».
- Line items сравнивай нормализованно (сортировка, decimal).

<Command cwd="projects/slotfill" title="Harness на test" code={`python -c "from src.eval.benchmark import main; main()"`} />

Не смотри результаты по полям и не возвращайся крутить промпт/LoRA «на пять минут». Это уже подгонка. Зафиксируй цифры.

<Trap title="Сравнение несравнимого">
Разный постпроцессинг, разный test, разная схема полей — таблица врёт.
</Trap>

**Готово, когда:** harness один, а не два скрипта с разными правилами.

**Ещё рано, если:** два ноутбука; разный parse; test перемешан с val.
