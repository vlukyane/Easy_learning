A делают **до** LoRA и не подкручивают после взгляда на B.

<Scaffold path="projects/slotfill/src/baselines/prompt.py">
Few-shot на 4–8 примерах из train (не test). Structured output в ту же схему, что LoRA.
</Scaffold>

Модель: Haiku, если поле-accuracy достаточна; иначе Sonnet. Логируй cost и latency каждого документа — потом $/1000.

Не оценивай A на train. Можно подкрутить промпт на val, test — один раз в главе 5–6.

<Command cwd="projects/slotfill" title="Прогон A на маленьком срезе val" code={`python -c "from src.baselines.prompt import run; run(split='val', limit=30)"`} />

Парсер выхода общий: если JSON кривой — поле пустое, текст модели не засчитывается. Иначе сравнение с LoRA несравнимо.

Ожидаемый вывод прогона A на срезе val:

```text
A prompt · split=val · n=30
  field-level 0.94   exact-doc 0.70   USD/1000 ~5.2   p50 900ms
```
