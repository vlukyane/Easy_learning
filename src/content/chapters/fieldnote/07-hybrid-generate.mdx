Retrieval гибридный: текстовые чанки и картинки сливаются в один ranked list. Generation — vision: модель видит **вырезанный регион**, не пересказ.

<Scaffold path="projects/fieldnote/src/retrieve.py">
`retrieve_hybrid(question, k)` — text hits + image hits, склейка RRF (не сумма разных cosine). Каждый hit с типом `text` или `image`. k тот же дух, что у baseline.
</Scaffold>

<Scaffold path="projects/fieldnote/src/generate.py">
`answer_multimodal(question, hits)` и `demo(question)`. Если hit типа image — в API уходит **файл PNG кропа** (страница целиком ок для v1, bbox — лучше). Не текстовое описание региона.

Ответ + citation `{ pdf, page, bbox }`. Vision-вызов через log_call. Сначала Haiku, Sonnet — если эвал слаб.
</Scaffold>

## Fusion

Reciprocal rank fusion не требует калибровки скоров разных модальностей. Начни с него. Не суммируй cosine от разных эмбеддеров как есть.

## Generation

Правило цитирования: если источник `image`, в модель идёт PNG кропа (страница целиком — допустимый v1, bbox — v2). Если источник `text`, картинку можно не слать.

Модель: сначала Haiku с vision, если эвал слаб — Sonnet. Каждый вызов через `log_call`.

<Command cwd="projects/fieldnote" title="Один визуальный вопрос вручную" code={`python -c "from src.generate import demo; demo('Какой момент затяжки для M8?')"`} />

`demo` печатает ответ и путь к кропу. Открой кроп: это должна быть та страница/регион, а не случайный титульный лист.

```text
Q: Какой момент затяжки для M8?
A: 25 Н·м
source: example-manual p.7  →  logs/citations/q001.png
```

Источник — картинка (`logs/citations/q001.png`), а не строка «см. стр. 7». Строкой цитата — незакрытый DoD.
