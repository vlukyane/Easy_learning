## Контракт лога

Каждый вызов модели пишет одну JSON-строку:

- `ts` — ISO-время
- `model`
- `step` — ingest_caption / retrieve / generate / eval
- `input_preview` — обрезанный вход
- `output_preview`
- `input_tokens`, `output_tokens`
- `latency_ms`
- `cost_usd` — хотя бы грубая оценка по прайсу
- `ok` / `error`

<Scaffold path="projects/fieldnote/src/log.py">
Допиши `log_call(...)`: одна JSON-строка в `logs/calls.jsonl` на каждый вызов модели. Поля как в контракте главы (ts, model, step, превью входа/выхода, токены, latency_ms, cost_usd, ok/error).

`smoke()` — крошечный запрос к Haiku, печать ответа, запись в лог. Cost можно считать по простой таблице цен в коде.
</Scaffold>

<Command cwd="projects/fieldnote" title="Проверить Haiku и лог" code={`python -c "from src.log import smoke; smoke()"`} />

Как выглядит вызов внутри `smoke()` (паттерн, не решение целиком):

```python
import anthropic
client = anthropic.Anthropic()  # ключ берётся из ANTHROPIC_API_KEY
resp = client.messages.create(
    model="claude-haiku-4-5-20251001",
    max_tokens=16,
    messages=[{"role": "user", "content": "ping"}],
)
print(resp.content[0].text)
usage = resp.usage  # .input_tokens, .output_tokens → в log_call
```

Когда допишешь `smoke()`, команда должна: сделать крошечный запрос к Haiku, напечатать ответ и дописать строку в `logs/calls.jsonl`. Ожидаемая строка лога:

```json
{"ts":"2026-09-25T10:00:00Z","model":"claude-haiku-4-5-20251001","step":"smoke","input_tokens":8,"output_tokens":12,"latency_ms":540,"cost_usd":0.00006,"ok":true}
```

<Action title="Открой JSONL глазами">
После smoke-вызова открой `logs/calls.jsonl` и проверь, что поля на месте. Если поля нет — лог бесполезен, чини сразу.
</Action>
