## Что это

**CSS Grid** — **двумерная** раскладка: и строки, и колонки сразу. Ты рисуешь сетку на контейнере, дети встают в ячейки.

Словарь на пальцах:

- **Линии** — границы сетки (как линии тетради).
- **Треки** — полосы между линиями: колонка или строка.
- **`fr`** — доля свободного места: `1fr 2fr` — вторая колонка вдвое шире первой из остатка.
- **`minmax(min, max)`** — трек не уже min и не шире max. Часто `minmax(0, 1fr)`, чтобы трек умел сжаться.

## Зачем

Визитка: слева текст, справа фото — это **и** колонки, **и** (если появятся блоки ниже) строки. Flex делает одну ось отлично; вторую ось им приходится эмулировать вложенными flex-контейнерами. Grid говорит: «две колонки, промежуток, на узком — одна».

Чем grid **не** flex: flex — ряд *или* столбец; перенос (`flex-wrap`) всё ещё одномерная лента. Grid держит клеточную карту.

## Как работает

Визитку удобно собрать grid:

```css
.layout {
  display: grid;
  grid-template-columns: minmax(0, 2fr) minmax(0, 1fr);
  gap: 1.5rem;
}
```

`minmax(0, …)` снова про сжимаемость. Одна колонка на узком экране — в главе про responsive.

Доска может остаться flex: три равных колонки в одном ряду — как раз одна ось.

<Checkpoint>
**Готово, когда:** сетка визитки двумерная (хотя бы две колонки на широком), длинное слово не ломает ширину окна.

**Как проверить:** DevTools grid overlay (значок grid). Computed у трека не раздут контентом.

**Ещё рано, если:** «сетка» — это таблица HTML; две колонки сделаны margin-left вручную; доску сломал, переведя её на grid без нужды и потеряв ряд.
</Checkpoint>
