## Что это

**Селектор** — адрес в дереве: «найди такие элементы». CSS не красит «файл целиком», он матчит узлы DOM.

Частые виды:

- **Элемент:** `p { … }` — все абзацы.
- **Класс:** `.card { … }` — только у кого `class="card"` (классов может быть несколько через пробел).
- **Потомок:** `.board li { … }` — `li` где-то внутри `.board`, не обязательно прямой ребёнок.
- **Псевдокласс:** `a:hover` — ссылка, пока курсор над ней. Это состояние, не новый тег.

## Зачем

Красить все `p` удобно для базового текста и опасно для карточки: подвал, форма, цитата тоже абзацы. **Класс** — имя роли в дизайне («карточка», «колонка»), его можно повесить на `article` и на `li`. Один тег — много обликов.

**id в стилях вреден:** специфичность как молоток. Потом `.card` не перебьёт `#hero`, начнётся гонка или `!important`. id оставь для якорей и `label for`.

## Как работает

Браузер идёт по дереву и спрашивает: этот узел подходит под селектор? `h1` — да, если тег `h1`. `.card` — да, если в списке классов есть `card`. `.column p` — да, если среди предков есть `.column`.

Специфичность по возрастанию: элемент (`h1`) < класс (`.card`) < id (`#hero`). Равные очки — побеждает правило **ниже в CSS**.

Подключи файл так: браузер грузит HTML, видит `<link rel="stylesheet" href="styles.css">`, запрашивает CSS **относительно HTML**, применяет.

В `<head>`:

```html
<link rel="stylesheet" href="styles.css" />
```

Класс на семантический тег нормален: `<header class="site-header">`.
