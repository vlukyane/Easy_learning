## Что это

Каждый элемент на странице — **коробка** (прямоугольник), даже круглая кнопка: скругление режет углы той же коробки.

Слои от центра наружу:

- **content** — текст или картинка, то, чему задаёшь `width` / `height`;
- **padding** — внутренний воздух между содержимым и рамкой;
- **border** — рамка;
- **margin** — внешний зазор до соседних коробок. Фон элемента margin не закрашивает.

**Block** (`p`, `div`, `h1`): занимает ширину родителя по умолчанию, соседи идут **сверху вниз**. Можно задать `width` и вертикальные margin.

**Inline** (`a`, `span`, `strong`): течёт в строке, как слова. `width` / `height` **не работают**. Горизонтальный padding да, вертикальный визуально странный (строка не раздвигается как блок).

**Inline-block:** в строке, как слово, но `width`/`height` можно. Редко нужен, когда flex уже есть.

## Зачем

Без модели коробок колонка «200px» внезапно шире: padding и border **добавляются** к width. Три колонки по 33% + padding = горизонтальный скролл. Кажется, что «flex сломался» — виноват box model.

## Как работает

По умолчанию `box-sizing: content-box`: `width` = только content. `border-box` — `width` уже включает padding и border. Сразу на всё дерево:

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

Вертикальные `margin` соседних блоков **схлопываются**: два по 20px между абзацами дают 20, не 40. Не лечи отрицательными маргинами, пока не увидел это в DevTools (Computed).
