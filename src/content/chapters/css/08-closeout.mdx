CSS не меняет **смысл** HTML: `h1` остаётся главным заголовком, колонка доски — списком карточек, форма — формой. Меняется только **представление**: ряд вместо столбика, цвет, воздух в коробке.

Своими словами:

- селектор выбирает узлы, каскад решает конфликт;
- коробка = content + padding + border, снаружи margin;
- flex — одна ось, grid — две;
- переменные на `:root`, чтобы не копировать цвет;
- media query — условие на ширину окна, не «другой сайт».

Пилот тот же: визитка и доска. Нового задания нет — доведи два брейкпоинта.

<DoD>
- 360 и 1200px без overflow-x.
- Колонки — flex или grid, не absolute.
</DoD>
