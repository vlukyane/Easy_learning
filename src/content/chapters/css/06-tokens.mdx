## Что это

**Каскадные переменные** — свойства с именем `--что-то`. Обычно объявляют на `:root` (это элемент `html`, корень дерева — все потомки видят переменную). Читают через `var(--ink)`.

Это не «ещё один язык». Это значение, которое **наследуется** и участвует в каскаде: на тёмной секции можно переопределить `--bg` локально.

Единицы:

- **`px`** — CSS-пиксель, фиксированный шаг (не «точка экрана телефона один в один»).
- **`em`** — относительно `font-size` **элемента** (вложенные em умножаются — легко раздуть).
- **`rem`** — относительно `font-size` **html** (корня). Предсказуемее для отступов и типа.
- **`vw`** — 1% ширины вьюпорта. Заголовок `10vw` на телефоне мелкий, на телевизоре огромный.
- **`clamp(min, предпочтительное, max)`** — значение между полом и потолком. Часто `clamp(1rem, 2vw, 1.5rem)`.

## Зачем

Цвет `#c9a227` в двенадцати правилах — смена темы = охота по файлу и промах. Один `--accent` на `:root` — поменял в одном месте. Хардкод «магических» чисел так же путает отступы.

## Как работает

На `:root`:

```css
:root {
  --bg: #111;
  --ink: #eee;
  --accent: #c9a227;
  --space: 1rem;
  --font: "Georgia", serif;
}

body {
  background: var(--bg);
  color: var(--ink);
  font-family: var(--font);
}
```

Размеры текста: `clamp(1rem, 2vw, 1.5rem)` — растёт с вьюпортом, но не бесконечно.

Не ставь десять разных `font-size` наугад. Две-три ступени: заголовок, подзаголовок, тело.

<Checkpoint>
**Готово, когда:** правка `--ink` (или `--bg`) в `:root` меняет вид в нескольких блоках сразу.

**Как проверить:** DevTools → клик по :root → поменяй переменную живьём. Заголовок с clamp не один px.

**Ещё рано, если:** переменные объявлены, но нигде не используются; десять разных font-size «на глаз».
</Checkpoint>
