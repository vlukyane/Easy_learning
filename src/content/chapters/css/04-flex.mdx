## Что это

**Flexbox** — раскладка **вдоль одной оси**. Контейнер (`display: flex`) выстраивает детей как вагоны.

- **Главная ось** — направление ряда: по умолчанию слева направо (`flex-direction: row`). Можно колонкой (`column`).
- **Поперечная ось** — перпендикуляр: в ряду это «вверх-вниз».

Роли:

- **Контейнер** получает `justify-content` (распределение по главной), `align-items` (по поперечной), `gap` (щель между детьми), `flex-direction`.
- **Предметы** (дети) получают `flex-grow / flex-shrink / flex-basis`. Короткая запись `flex: 1 1 0` значит: расти, сжиматься, стартовая ширина 0 — колонки делят место поровну.

## Зачем

Три колонки доски в HTML идут друг под другом (блоки). Нужен ряд на широком экране **без таблицы и без `float`**. Flex — «сделай из детей ряд (или столбец) и разрули свободное место».

**Когда ещё не grid:** одна линия (ряд карточек, шапка: логотип слева, меню справа). Две оси сразу (и строки, и колонки шахматки) — следующая глава.

## Как работает

На контейнер колонок:

```css
.board {
  display: flex;
  gap: 1rem;
  align-items: flex-start;
}

.column {
  flex: 1 1 0;
  min-width: 0;
}
```

`min-width: 0` — иначе flex-дети не сжимаются ниже «естественной» ширины контента (длинное слово, картинка) и появляется горизонтальный скролл.

`gap` вместо margin на каждом ребёнке: не нужно обнулять крайние.

Не центрируй всё через `position: absolute`. Flex умеет `justify-content` и `align-items`.

<Checkpoint>
**Готово, когда:** на десктопе колонки в ряд, в DevTools у контейнера display:flex, gap задан на родителе.

**Как проверить:** потяни окно. Пока без media query ряд может сплющиться — главное, что flex включён и min-width: 0 не даёт вылезти слову.

**Ещё рано, если:** колонки absolute; float; таблица «для ряда»; gap нет, зато margin у каждого ребёнка.
