Без фреймворка ты уже умеешь **состояние**: массив карточек, события его меняют, экран перерисовывается, storage держит строку JSON. **React заменит проекцию** (ручной `appendChild` → описание JSX), не идею «данные отдельно, картинка отдельно».

Своими словами:

- один язык, хост браузера ≠ хост Node;
- объект карточки с `id`;
- DOM слушает события, форма без `preventDefault` перезагружается;
- `localStorage` — не бэкенд.

<DoD>
- Карточки добавляются и переживают перезагрузку.
- Нет React. Нет innerHTML из сырого ввода.
</DoD>

Дальше React **перепишет** UI, логику данных можно перенести. Не удаляй js-пилот: это baseline «без фреймворка».
