## Что это

**JavaScript** — язык с **побочными эффектами**: кроме формул он меняет страницу, пишет в storage, печатает в консоль. Это не «только математика».

Движок в Chrome (**V8**) — родственник движка в Node: тот же язык (`const`, функции, массивы). **Хост другой**:

- в браузере вокруг языка — DOM, `document`, `window`;
- в Node — файлы, `process`, сеть сервера; **DOM нет**.

Аналогия: один актёр, две сцены. Реплики те же, реквизит разный. Вызвать `document` в `node file.js` — как искать кулисы на пустом складе.

**Модуль** — файл, который явно отдаёт наружу (`export`) и берёт чужое (`import`). Без модулей всё свалено в одну глобальную кучу.

## Зачем

Без JS страница статична: HTML+CSS показывают доску, но «добавить карточку» нельзя. Без понимания хоста новичок запускает браузерный файл через Node и думает, что «JS сломан».

## Как работает

Браузер парсит HTML. Когда доходит до `<script>`, качает и выполняет код. Скрипт **в конце `body`** видит уже построенное дерево. Скрипт в `head` без `defer` может бежать, пока `div.board` ещё нет — `querySelector` вернёт `null`.

```html
<script type="module" src="board.js"></script>
```

`type="module"` включает строгий режим и `import`/`export` без сборщика. Модули по умолчанию откладываются (как `defer`): HTML дорисуется, потом скрипт.
