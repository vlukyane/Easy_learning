## Что это

**`localStorage`** — словарик **ключ → строка** в **профиле браузера** для этого сайта (точнее, origin: протокол + хост + порт). Это не сервер, не база, не секрет: любой JS на странице может прочитать. Синхронный API: запись тормозит вкладку на миллисекунды. Лимит порядка **5 МБ** на origin. Закрыл браузер — данные обычно живут; приватное окно — часто нет.

**Модули ES:** `export` отдаёт функцию или константу из файла. `import { load } from "./storage.js"` берёт. **`type="module"`** в `<script>` включает этот режим. В пути для браузера **расширение `.js` обязательно** — это URL, не догадка Node.

## Зачем

Массив карточек живёт в RAM вкладки. F5 убивает RAM. Без storage доска — игрушка на один заход. Без модулей `board.js` раздувается в простыню: смешаны DOM, JSON, кнопки — сложнее искать баг.

Боль: положил объект в `setItem` без `stringify` — браузер сохранит `"[object Object]"`. Прочитал без `parse` — работаешь со строкой, `.filter` нет.

## Как работает

```js
localStorage.setItem("study-board", JSON.stringify(cards));
const raw = localStorage.getItem("study-board");
```

Ключ свой, не чужой (`ai-learning-progress-v1` — это портал, не трогай).

Модули: `export function render()` в `board.js`, при росте — `storage.js` + `import { load, save } from "./storage.js"`.

`file://` модули часто режет безопасность. Если import не грузится — позже Vite/`npx serve`. Пока можно один `board.js` без import.
