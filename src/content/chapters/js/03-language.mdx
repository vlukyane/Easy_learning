## Что это

**Значение** — данные: число `2`, строка `"карточка"`, объект `{ title: "…" }`. **Переменная** — имя-ярлык, привязанное к значению. `const title = "HTML"` — ярлык `title` нельзя перевесить на другое значение. Само значение-объект при этом **можно менять изнутри** (`card.title = "CSS"`): `const` защищает **привязку**, не содержимое объекта.

**Примитивы** — «коробки с одним куском»: строка, число, boolean, `null`, `undefined`. Сравниваются по значению. **Объекты** (включая массивы и функции) — ссылки на место в памяти. Два объекта с одинаковыми полями — не `===`.

**`===`** — строгое равенство без приведения типов. **`==`** сначала приводит (`"0" == false` — true) и путает.

**Function declaration** — `function add(a, b) { return a + b }`: имя поднимается, можно вызвать строкой выше в том же модуле. **Arrow** — `const add = (a, b) => a + b`: нет своего `this`, удобно как колбэк. Для обработчиков DOM стрелка часто плюс.

**`undefined`** — «значения нет»: забытый `return`, нет свойства, переменная объявлена без значения. Это не то же самое, что **ошибка** (`ReferenceError`, `TypeError`): ошибка останавливает выполнение, `undefined` — тихое «пусто».

## Зачем

Боль без этого: карточка «не добавляется», потому что функция ничего не `return`; или `cards = …` падает, потому что `const`; или `"1" == 1` проходит тест и ломает колонку.

## Как работает

`const` — по умолчанию. `let` — если переменная переназначается. `var` не используем (область видимости дырявая).

```js
const n = 1;
n === 1; // true
n === "1"; // false
```

Ошибки:

- присваивание в необъявленную переменную в модуле кинет ReferenceError;
- `const x = 1; x = 2` — TypeError;
- забытый `return` даст `undefined`.
