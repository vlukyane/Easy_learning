## Что это

**DOM** — живое дерево после парса HTML. Теги в файле стали **узлами** в памяти: их можно найти, слушать, менять. Файл на диске при этом сам не переписывается — меняется модель в браузере.

**`querySelector`** — «найди первый узел, подходящий под CSS-селектор». `querySelectorAll` — все. Не нашёл — `null` / пустой список. Вызов на `document` ищет по всей странице; на элементе — только внутри него.

**Событие** — «что-то случилось»: клик, submit, ввод. У события есть **цель** (`event.target` — самый внутренний узел под курсором). **Всплытие** — событие поднимается к родителям: клик по кнопке внутри колонки слышит и колонка, и `document`.

**Делегирование** — один слушатель на родителя вместо сотни на каждой кнопке. Особенно нужно, когда кнопки рисуешь заново каждый `render()`.

**`preventDefault`** — отменить действие браузера по умолчанию. У формы это **отправка и перезагрузка** страницы.

**`innerHTML`** опасен: строка становится разметкой. Заголовок карточки `<img onerror=…>` выполнит код. Для текста пользователя — **`textContent`**.

## Зачем

Без DOM JS не «нажмёт» на страницу. Без `preventDefault` карточка «мелькнёт и исчезнет» — на самом деле страница перезагрузилась, массив в памяти умер. Без делегирования новые карточки «не кликаются».

## Как работает

Скопируй разметку доски из CSS-темы в `projects/web/js/board.html`. Подключи модуль:

```html
<script type="module" src="./board.js"></script>
```

Не ставь обработчик на каждую кнопку в цикле innerHTML. Лучше делегирование:

```js
document.querySelector(".board").addEventListener("click", (e) => {
  const btn = e.target.closest("[data-move]");
  if (!btn) return;
  // ...
});
```

Форма добавления: `submit` + `event.preventDefault()`, иначе страница перезагрузится и «карточка исчезнет» ещё до persist.
