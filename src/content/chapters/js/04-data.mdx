## Что это

**Массив** — упорядоченный список: `[карточка, карточка]`. Индекс с нуля, длина — `.length`. Порядок колонок доски = порядок в массиве или поле `column` у каждой карточки.

**Объект** — словарь **ключ → значение**: `{ id: "c1", title: "HTML: стенд", column: "todo" }`. Ключи — имена полей. Это не «ещё один массив».

**`id` у карточки** — стабильное имя человека в паспорте, не номер в очереди. Индекс массива после удаления середины сдвигается — перепутаешь, кто есть кто. Строка `id` (хотя бы `crypto.randomUUID()` или `c` + Date.now()) переживает перестановки.

**`map` / `filter`** возвращают **новый** массив: исходный не режут. `filter` оставляет тех, для кого функция дала true. `map` превращает каждый элемент (карточка → заголовок).

**JSON** — **текст** в договорённом виде (`"[{...}]"`), не четвёртый тип данных JavaScript. Живой массив в памяти ≠ строка. **`JSON.stringify`** — объект/массив → текст (чтобы положить в localStorage). **`JSON.parse`** — текст → объект. Битый текст кидает исключение.

## Зачем

Доска — список карточек. Без объекта непонятно, в какой колонке карточка. Без `id` удаление «второй» удалит не ту после сортировки. Без JSON localStorage не примет массив «как есть» — только строки.

## Как работает

```js
{ id: "c1", title: "HTML: стенд", column: "todo" }

const next = cards.filter((c) => c.id !== id);
const titles = cards.map((c) => c.title);
JSON.stringify(cards);
JSON.parse(text);
```

`parse` кидает, если строка битая — оберни в `try/catch` и откатись к `[]`.

Частые путаницы: `cards.map` без `return` в фигурных скобках даст массив `undefined`; `filter` не меняет исходник, нужно писать в переменную / в state.
