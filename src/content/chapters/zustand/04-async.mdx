## Что это

**Action может быть `async`.** Стор — не «только синхронный Redux 2015». Функция `load` ждёт сеть, потом вызывает `set` с результатом. Пока ждёт, можно `set({ loading: true })`.

**`fetch`** в браузере качает URL (у нас `/cards.json` из `public`). Ответ — тело; `res.json()` парсит текст в объект. Ошибку сети кладут в поле стора `error`, не в `alert`.

## Зачем

Без async всё «уже в памяти». Учебный JSON — как будто сервер отдал стартовые карточки. Боль: fetch в каждом компоненте, гонки, двойная загрузка. Action в сторе — одно место.

## Как работает

Положи `public/cards.json` с учебными карточками. Action:

```js
load: async () => {
  const res = await fetch("/cards.json");
  const cards = await res.json();
  set({ cards });
},
```

В компоненте не дублируй fetch в useEffect, если загрузка — часть стора: `useEffect(() => { useBoard.getState().load(); }, []);`

`get()` внутри create даёт текущее состояние для compose actions.

**Готово, когда:** доска умеет стартовать с файла, ошибка не только в console.
