## Что это

**`create`** делает хранилище: объект состояния + функции, которые его меняют.

**`set`** записывает **кусок** state (мерж верхнего уровня): `set({ cards: next })` или `set((s) => ({ cards: [...s.cards, card] }))`. Не мутируй `s.cards.push`.

**Action** — функция в сторе, которая вызывает `set` (и иногда `get`). Компонент не раскидывает логику «как склеить карточку» — вызывает `add(title)`.

**Хук-подписка:** `useBoard((s) => s.add)` — компонент слушает выбранное. Без селектора (`useBoard()`) — слушает **всё**, ререндер на любой чих.

**`npm install zustand`** пишет пакет в `package.json` **и** кладёт код в `node_modules`. Это не «включилось в React само».

## Зачем

Без actions карточки снова собирают в `App`. Без понимания `set` новичок делает `state.cards.push` — UI молчит. Без локального install импорт `zustand` красный.

## Как работает

В том же приложении, что React/Vite:

<Command cwd="projects/web/react" title="Установка zustand" code={`nvm use 22
npm install zustand
node -e "console.log(require('./package.json').dependencies.zustand)"`} />

Ожидание: в выводе номер версии, в `package.json` появилась зависимость.

Минимальный стор `src/store/board.js`:

```js
import { create } from "zustand";

export const useBoard = create((set) => ({
  cards: [],
  add: (title) =>
    set((s) => ({
      cards: [...s.cards, { id: crypto.randomUUID(), title, column: "todo" }],
    })),
}));
```

В компоненте: `const add = useBoard((s) => s.add);` — не весь стор сразу.

Если хочешь отдельную копию проекта — скопируй `projects/web/react` в `projects/web/zustand` после install.
