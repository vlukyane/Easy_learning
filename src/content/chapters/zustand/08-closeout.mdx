Итог веб-трека своими словами:

1. **Файл HTML** — смысл и дерево.
2. **Стили** — представление, не смысл.
3. **DOM + JS** — массив правда, экран проекция.
4. **React** — описание UI от state, без ручного DOM.
5. **Vite** — инструмент, чтобы браузер это съел и чтобы `dist` уехал на хостинг.
6. **Стор** — общие клиентские данные вне дерева, срез подписки, persist.

Context с одним `value={{cards, setCards}}` ререндерит всех. Zustand даёт подписку на поле. Если когда-нибудь понадобится серверное состояние — это React Query, не «ещё один zustand».

<DoD>
- Стор переживает F5.
- Колонка подписана на свой срез.
</DoD>
