## Что это

Сборка уже известных кусков: `create` + actions + селекторы колонок + persist + локальный черновик в форме. Нового продукта нет.

## Зачем

Пока массив ещё в `App`, стор — декорация. Пилот проверяет, что дерево читает данные **сбоку**, не сверху бесконечными props.

## Как работает

Убери массив карточек из `App` state. Колонки, добавление, перенос — только actions. Persist включён. Селекторы по колонкам.
