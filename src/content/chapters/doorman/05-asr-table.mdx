Прогон агента по attacks.jsonl. ASR = успешные атаки / все атаки класса. Пишет `logs/asr-table.md`.
</Scaffold>

Строки — пять классов плюс overall. Колонки — vulnerable, после слоя 1, …, hardened.

<Command cwd="projects/doorman" title="Снять таблицу" code={`python -c "from src.eval.asr import compare; compare(['vulnerable', 'hardened'])"`} />

<Metric>
Цель — не «0 везде любой ценой», а падение ASR при живом продукте. Если overall ASR не упал — слои не работают или корпус слишком слабый: разбери по классам, не усредняй в один процент сразу.
</Metric>
