Сводка пилота: **state → JSX → экран**. Массив карточек в родителе (или в custom hook), колонки получают props, клик вызывает setter, React перерисовывает описание. Прямого DOM (`document.createElement`, `querySelector` ради UI доски) нет.

Нового задания нет: доведи ту же доску до DoD.

Своими словами: компонент — функция; props вниз; state — память; эффект — внешний мир; JSX — не HTML.

<DoD>
- Карточки из массива state.
- Нет document.createElement в UI доски.
- Нет коврового memo.
</DoD>

Сотри стартовый логотип Vite из `App.jsx`. Доска — главный экран.

Детали `vite.config` — следующая тема; сейчас достаточно `npm run dev`.
