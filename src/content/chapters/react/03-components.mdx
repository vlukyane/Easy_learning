## Что это

**Компонент** — функция, которая возвращает JSX. Вызвал `<Column title="Сделать" />` — React вызовет `Column({ title: "Сделать" })`.

**Props** — входные данные **вниз**: родитель передаёт, ребёнок читает. Это аргументы функции, не глобальная переменная. Ребёнок **не присваивает** в `props.title`.

**Композиция** — собрать экран из кусков (`Column` внутри `Board`), а не копировать три раза одну разметку. `children` — специальный prop: всё, что написали между тегами `<Column>…</Column>`.

**Имя с большой буквы** (`Column`, не `column`): так React отличает компонент от обычного HTML-тега. `column` он попытается создать как `<column>` в DOM — такого тега нет.

## Зачем

Три колонки доски почти одинаковые. Копипаста — правка заголовка в трёх местах и баг в четвёртом. Props дают одно место правды для «как выглядит колонка», разные только данные.

## Как работает

```jsx
function Column({ title, children }) {
  return (
    <section className="column">
      <h2>{title}</h2>
      {children}
    </section>
  );
}
```

Данные вниз, события вверх (кнопка «перенести» вызовет функцию, которую передал родитель — в главе state).

Один файл — один основной компонент плюс мелочь. Пока не дроби на 30 файлов.
