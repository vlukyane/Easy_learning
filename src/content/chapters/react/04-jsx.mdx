## Что это

В JSX **фигурные скобки** — дырка в JavaScript: `{card.title}`, не шаблонная строка HTML. Внутри — **выражение** (то, что имеет значение), не произвольный `if` на несколько строк. Условие: `{count > 0 && <p>есть</p>}` или тернарник.

**Список** рисуют через `.map`, который возвращает массив элементов. **`key`** — личность элемента **между рендерами**: React понимает, что карточка `c1` — та же, даже если сдвинулась в другой колонке. Индекс массива — номер в очереди, не личность.

**События** — **функции**: `onClick={handler}`. В HTML были строки в атрибутах (`onclick="…"`) — здесь так нельзя. React передаст объект события; у формы по-прежнему нужен `preventDefault`.

**Фрагмент** `<>…</>` — несколько узлов без лишней обёртки-div (div ломает flex/grid).

## Зачем

Без `key` React при перестановке карточек может оставить внутренний state не тому `li` (текст в инпуте «прилипнет» к соседу). Без фигурных скобок заголовок будет буквально `{card.title}` на экране.

## Как работает

```jsx
{cards.map((card) => (
  <li key={card.id}>{card.title}</li>
))}
```

`key` — стабильный id, не индекс, если список переставляется.

События: `onClick={handler}`, не строки. Обработчик получает SyntheticEvent; для формы `onSubmit` + `preventDefault`.
