## Что это

**Рендер должен быть чистым:** одни и те же props/state → тот же JSX, без записи в storage, без `fetch`, без `document.title` в теле функции. Иначе React (особенно Strict Mode) вызовет рендер дважды — побочный эффект удвоится.

**Эффект** — «после отрисовки сходи во внешний мир». `useEffect` регистрирует эту работу. **Массив зависимостей** — «запустись снова, только если вот эти значения изменились».

**`useRef`** — коробка `{ current: … }`. Смена `.current` **не** вызывает рендер. Нужна, чтобы держать DOM-узел (фокус) или значение «для себя», не для экрана. Список карточек в ref как правда — антипаттерн: экран не узнает.

## Зачем

`localStorage.setItem` в теле компонента сработает на каждый рендер, в том числе «просто так». Эффект с `[cards]` пишет, только когда карточки реально другие. Без зависимостей эффект после каждого рендера. С `setState` внутри бездумного эффекта — **цикл** эффект↔setState: экран мигает, вкладка греется.

## Как работает

```jsx
useEffect(() => {
  localStorage.setItem("study-board", JSON.stringify(cards));
}, [cards]);
```

Пустой массив зависимостей — «один раз после монтирования». Нет массива — эффект после **каждого** рендера (почти всегда ошибка).

Цикл: эффект пишет setState → рендер → эффект. Лечится правильными зависимостями или уходом от «эффекта ради вычисления» (вычисление — в рендере или в `useMemo`, не в эффекте).

Фокус поля: `inputRef.current.focus()`.
