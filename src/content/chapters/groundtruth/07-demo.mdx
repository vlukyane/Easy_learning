Гейт, который ни разу не краснел — не проверен.

<Scaffold path="projects/groundtruth/src/retrieve.py">
В отдельной ветке (или в грязном дереве, которое **не** пойдёт в основную линию) испорти `retrieve`, чтобы recall заведомо просел ниже baseline минус epsilon.

**Хватит одной порчи:** случайные id; всегда `k=1`; индекс по половине корпуса; выдача задом наперёд; игнор query и один и тот же набор документов. Цель — увидеть ненулевой exit, не «придумать хитрый баг на проде».

Не коммить порчу в main. После красного прогона верни код как был и снова запусти гейт.
</Scaffold>

<Scaffold path="projects/groundtruth/logs">
Сохрани доказательства обоих цветов: `logs/gate-red.txt` и `logs/gate-green.txt` (полный stdout и строка с exit). Если есть GitHub — PR с порчей и скрин красного job тоже считаются; без remote двух локальных прогонов достаточно для учебного DoD.

В файле должно быть видно `GATE_FAIL` / `GATE_OK` и числа recall vs baseline, не обрезанное «exit 1» без контекста. Папку `logs/` создай, если её ещё нет.
</Scaffold>

<Action title="Сломай retrieval в ветке">
Временная порча: `retrieve` возвращает случайные id, или `k=1`, или индекс из половины корпуса. Не коммить это в основную линию.
</Action>

<Command cwd="projects/groundtruth" title="Красный локальный CI" code={`python scripts/ci_eval.py; echo exit:$?`} />

Ожидание: exit ≠ 0 и в отчёте recall ниже baseline − ε.

<Command cwd="projects/groundtruth" title="Вернуть как было и снова зелёный" code={`python scripts/ci_eval.py; echo exit:$?`} />

Если есть GitHub — сделай PR с порчей и прикрепи скрин красного job. Если нет — двух локальных прогонов достаточно для учебного DoD; запиши вывод в `logs/gate-red.txt` и `logs/gate-green.txt`.

Если всё ещё OK — порча слишком слабая (убрал один документ из пятисот). Не останавливайся на «ну наверное упадёт»." },
  { id: "green", label: "После отката гейт снова зелёный", hint: "Верни retrieve (git checkout или отмена правок). Повторный ci_eval → exit 0, GATE_OK, recall снова около baseline. Если зелёный не вернулся — откатил не всё: индекс на диске, константа K, другой gold." },

Сначала красный прогон — сохрани лог. Потом откат — зелёный прогон и второй лог. Без двух артефактов главу закрывать рано.
</Practice>

<Checkpoint>
**Готово, когда:** ты видел оба цвета гейта своими глазами и можешь показать артефакты.

**Как проверить:** открой два лога (или PR + локальный green). В красном — ненулевой exit и просевший recall; в зелёном — exit 0 после отката. В основной ветке порчи `retrieve` нет.

**Ещё рано, если:** только красный или только зелёный; логи не сохранены; порча закоммичена в main; `ci_eval` не запускался, «и так понятно что упадёт».
</Checkpoint>
